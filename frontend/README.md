# M1 显控前端

本前端只显示后端事件、提交配置与控制运行，不计算光学传播、定位或误差统计。所有默认数据均为 `DEMO_UNCALIBRATED`。

## 本地运行

在本目录执行 `npm ci`、`npm run dev`，打开 `http://127.0.0.1:5180`。Vite 固定端口，API、WebSocket 与资产代理至 `http://127.0.0.1:8010`。后端启动方法见项目 `docs/demo-guide.md`。

执行 `npm run test -- --run` 运行事件、控制请求、回放顺序和后端指标展示测试；`npm run build` 先进行 TypeScript 类型检查再打包。

## 相机模型控制

选择 C1/C2/C3 等相机，可编辑 X、Y、架设高度、指向位置及内参；也可在三维视图中拖动该相机的坐标轴。模型使用 Blender 导出的 `camera_unit.glb`。GLB 加载失败时保留几何体降级和可见的失败状态。

运行配置在启动时冻结：运行和暂停期间不编辑相机。停止后调整参数，再启动新运行，后端使用新配置生成观测。此行为避免将修改后的模型显示误认为旧运行仍在使用新标定。

控制请求的 HTTP 确认可能早于 WebSocket 中已记录的波面、轨迹事件到达。连接正常时，界面会保持控制忙碌，等待事件序号达到响应中的记录水位，再完成按钮状态更新；运行状态以事件流的 `run_status` 为准。等待超过 5 秒会明确提示显示尚未同步，不伪报暂停成功。

完整 Blender 场景的静态相机、支架、标签、视锥、UUV、轨迹与 `water_surface` 隐藏，动态模型由配置和后端事件驱动；源 GLB 不改写。显示视锥为空气侧几何示意。

## 后端波面显示

选择“波纹 Snell 折射”并启动新运行，前端从 `water_surface` 事件读取网格范围、行列数、行优先高度和法向量，将它们直接放入 Three.js `BufferGeometry`。没有客户端波纹公式、随机扰动或随墙钟推进的水面 shader。平面模式显示后端给出的零高度网格；未接收波面事件时标注“平均平面示意”，包括不含新事件的旧日志。

暂停后网格保持最后一个事件的高度；JSONL 回放按原事件恢复同一水面。界面显示后端采样时刻、网格大小和模型 ID。默认显示真实高度 ×1；×3/×5 仅改变显示对象的垂直缩放，并明确标注，不修改原始高度、后端折射或误差评价。水面可随时隐藏。

在“算法接入 · 2.1—2.3”中可查看后端已注册算法的版本、契约和占位状态，选择注册 ID 后通过新运行生效。新算法仍需按项目接口规范注册并通过契约测试。

## 后端契约同步

公开配置与事件类型来自后端 Pydantic 模型，生成到 `src/generated-contracts.ts`。在项目根目录使用指定环境执行：

```powershell
& 'D:\_DownloadDeepLearning\Anaconda\envs\UUV\python.exe' frontend/tools/generate_contracts.py
& 'D:\_DownloadDeepLearning\Anaconda\envs\UUV\python.exe' frontend/tools/generate_contracts.py --check
```

生成类型包含有效配置中已补齐的默认字段，不代替后端输入校验。前端自己的姿态展示、误差点、指标列等状态定义于 `src/contracts.ts`。

## 回放与指标

回放读取服务器已落盘的 JSONL 事件，不重新运行定位。事件序号用于排序、补发和去重；不同运行不可混合。

精度展示优先使用后端 `common_valid_metrics` 的共同有效帧结果，同时保留各方法自身的有效率。回放中的汇总指标来自该运行的后端最终统计，界面明确标为历史最终汇总；误差曲线随已回放事件推进。

当前打包包含 Three.js 和 ECharts，生产构建有大于 500 kB 的单包警告。构建仍通过；本地原型尚未做按需分包优化。
