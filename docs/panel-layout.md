# 工作台窗口与布局

本次按用户提供的 VSCode Light 截图调整为中性灰标题栏/侧栏、白色内容区、深色文字、蓝色选中状态，替换之前偏浅的蓝白配色。

- 两侧竖向分隔条：拖动调整配置栏与评价栏宽度；聚焦后左右方向键每次调整 20 px。
- 各面板底部横条：拖动调整高度；聚焦后上下键每次调整 20 px；双击恢复自动高度。
- 标题栏方框：最大化/还原；双击标题栏也可切换，Esc 还原。
- 标题栏 ×：隐藏面板，保留已挂载的视图与运行/回放状态，不停止后端运行。
- 顶部“窗口”菜单：重新打开任一关闭的面板，或恢复全部默认布局。
- 栏宽、面板高度和关闭状态存于当前浏览器 localStorage；不进入仿真配置、配置哈希或 JSONL。
- 窄屏采用纵向排列，竖向栏宽分隔条隐藏；面板高度与关闭控制仍可使用。

实现：frontend/src/DockPanel.vue、App.vue、style.css。无需新增依赖；后端、原有 GLB 与物理模型没有改动。

实际验收：Playwright 在本地页面通过真实鼠标拖动检查高度增长、栏宽增长；检查最大化/Esc、关闭/菜单恢复、关闭侧栏后的重排、刷新持久化与恢复默认布局。截图：output/playwright/vscode-layout.png。前端现有 10 项测试通过；生产构建通过（保留大包体积提示）。
