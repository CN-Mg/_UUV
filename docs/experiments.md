## 科学性解释

- 无噪声平面校正近零误差是同模型反演的数值一致性，不能据此宣称设备精度。
- 简单平滑在无噪声运动上引入滞后，误差大于未平滑的校正结果；这一负面结果保留，不能把“加滤波”直接写成精度提升。
- 本批六个有波片段和像素噪声片段中，平滑后的总定位 RMSE 也高于未平滑校正；目前没有证据将这一简单平滑基线报告为有效的波纹误差抑制算法。
- 有波结果需逐种子查看，只有在具体条件下有效才能声称该条件下的演示改善；三秒片段不是独立验证或完整航迹统计。
- 波面求解是平面初值附近的局部费马驻点，并抽样排除明显重复穿越；没有证明全局最短路径或完备多路径检测。
- 尚无独立真实图像/水池标定数据；2.1 优化与 2.3 融合仍为占位。
