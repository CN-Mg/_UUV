# 已知限制

- 所有默认参数和仿真结论为 `DEMO_UNCALIBRATED`，未通过独立水池数据校准。数值近零的同模型反演结果不代表真实设备精度。
- 观测来自解析投影，目标与标记关联预先已知；没有读取真实相机图像、检测 ArUco、评估识别率或解决真实多目标关联。
- M1 以水平圆轨迹和水平航行假设起步，不是完整水动力学、任意轨迹或阵型控制系统。UUV-001 约 2.8 m 的尺寸为概念资产。
- 已知平均平面与折射率的校正属于 `MODEL_AWARE_DEMO`。波纹生成器的真实相位、种子和瞬时波面不提供给基线估计器。
- 少量正弦分量描述小坡度运动波面，没有破碎波、泡沫、散射、浑浊、镜面高光、运动模糊或真实镜头畸变建模。
- 正面、图像边界和视场判断不等于真实检测概率；完整网格自遮挡与目标间遮挡尚不属于 M1 基线保证。
- 相机、水池、水面和空气侧视锥的 Blender 几何用于示意。水面显示使用后端同源波面采样，但图形网格、显示放大和模型外壳不参与光学求解。
- 相机编辑是草稿预览；后端运行使用不可变配置快照，停止并重新启动后才采用新外参。
- `FixedLayoutAdapter` 未执行最优布局，输出 `NOT_OPTIMIZED`；几何网格覆盖不等于真实定位精度。2.1 算法由后续同学接入。
- `NoOpFusion` 输出 `PASSTHROUGH_NOT_FUSED`，没有利用声学/通信提升精度。2.3 的正式时空对齐、融合与独立验证留待接入。
- 观测时间目前需要已映射到仿真时钟；没有真实设备驱动、设备时钟同步或复杂乱序测量补偿。通信转发测量不作为独立观测重复计权。
- 固定步长不保证所有配置都达到 1× 墙钟实时；运行速度、耗时和失败状态必须按实际结果报告。较多相机/目标或波纹光路会增加计算量。
- 本批轻量实验中，固定系数简单平滑未改善有波片段的总定位 RMSE；它是供后续替换的对照基线，不能作为已成功实现波纹抑制的证据。
- 服务重启后保存的运行可回放，但不会恢复原计算线程；中断状态与正常结束应区分。
- M1 在内存中缓存活跃运行事件，导出时读取文件内容快照，适用于起步阶段的小型场景；长时间、大规模多目标历史尚未采用分页/流式存储优化。
- 自动化测试、构建、实际浏览器交互和科研实验分别记录。未执行项目不得因其他测试通过而推定已通过。
